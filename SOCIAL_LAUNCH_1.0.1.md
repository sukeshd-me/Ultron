### Description
ULTRON is a Windows personal AI command center developed under **UPAI Technologies** (Founder: **Sukesh D.**).

v1.0.1 introduces:
- **Redesigned Futuristic Command-Center Interface**: High-tech glassmorphism HUD, central reactive Three.js 3D core, and clean, simplified navigation.
- **Simplified Chat-First Experience**: Focuses on core interaction—*"Talk to ULTRON and it handles the rest"*—with natural voice and text input.
- **NVIDIA AI First-Run Onboarding**: Dedicated setup flow for NVIDIA API Foundation keys with live ping latency testing and direct official catalog linking.
- **Secure Hardware Credential Vault**: Hardware-isolated DPAPI storage (`credentials.vault`) for sensitive phone PINs and passcodes with guaranteed zero SQLite/log leakage.
- **Android ADB Integration**: Real-time phone telemetry (device model, Android OS version, battery status) and automated screen wake / secure unlock keyevents.
- **Expanded Persistent Action Memory**: Every command records audited execution status, real measured timestamps, and `duration_ms` with automated secret redaction.
- **Hybrid Online/Offline Operation**: Sub-50ms deterministic local fast-track routing for all Windows tools without cloud network dependency.
- **Hardened Security Architecture**: Strict typed tool schemas (39 audited tools) preventing arbitrary script execution.

## 4. Reddit Post (r/programming, r/windows, r/artificial)

**Title**: ULTRON v1.0.1: I updated my open-source AI Command Center for Windows with Android ADB control, DPAPI vault, and an offline-first architecture

**Body**:
Hey everyone!

Founder of UPAI Technologies here. A while back I shared the initial concept of ULTRON, a desktop AI command center engineered natively for Windows 11. Today, I'm thrilled to release **ULTRON v1.0.1**.

### The Problem with Most AI Assistants:
Web-based chatbots are completely isolated from your desktop environment. They can tell you the command to type, but they can't actually run your system diagnostics, launch your applications, manage your files, or interface with your phone.

### What ULTRON v1.0.1 Brings:
- **Simplified Chat-First Interface**: Clean futuristic command console with a central reactive Three.js particle core.
- **Zero-Storage DPAPI Credential Vault**: When automating Android phone unlocks via ADB, your device PIN is encrypted with Windows DPAPI in `%APPDATA%/ultron/credentials.vault`. It is **never** written to SQLite databases, logs, or sent to an LLM.
- **Typed Tool Architecture**: 39 strictly typed tools in TypeScript. The agent cannot generate arbitrary unconstrained PowerShell text.
- **Offline-First Fast-Track Router**: Queries like *"What's my CPU usage?"* or *"Open Calculator"* execute locally in <50ms without hitting cloud APIs.
- **First-Run NVIDIA Onboarding**: Smoothly connects to NVIDIA Cloud AI or runs 100% offline with zero cloud dependency.
